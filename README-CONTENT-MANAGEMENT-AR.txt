تحديث إدارة محتوى موقع نادي العقيق الأزرق

1) أضيفت لوحة «إدارة محتوى الموقع» داخل admin.html وتظهر بعد تسجيل الدخول بحساب Admin.
2) يمكن إدارة العناصر التالية بالإضافة والتعديل والحذف والإظهار والإخفاء:
   - الإعلانات: clubAnnouncements
   - العروض والأسعار: clubOffers
   - نظام النادي والباقات: clubPlans
   - مواعيد الدوام: clubHours
   - جدول الكلاسات: clubClasses
   - تعليمات النادي: clubRules
3) صفحات الموقع العامة تقرأ البيانات المنشورة من هذه المجموعات.
4) أضيف ملف دليل الأجهزة داخل assets/device-guide.pdf ويعرض داخل صفحة الموقع دون تحويل المشتركة إلى Google Drive.

مهم قبل رفع التحديث:
- افتحي Firebase Console > Firestore Database > Rules.
- استبدلي القواعد الحالية بمحتوى firestore.rules الموجود في هذه الحزمة ثم اضغطي Publish.
- لا تستخدمي قواعد مفتوحة للكتابة. القواعد المضافة تسمح بالقراءة العامة لمحتوى النادي، والكتابة لحسابات Admin فقط.
- ارفعي جميع الملفات مع الحفاظ على بنية المجلدات، خصوصًا assets/device-guide.pdf.
- ارفعي ملفات المشروع إلى GitHub وانتظري اكتمال GitHub Pages.

ملاحظات:
- حقول الصور في الإعلانات والعروض تقبل رابط صورة مباشر حاليًا؛ لا يوجد رفع صور من لوحة التحكم في هذا الإصدار.
- دليل الأجهزة ملف PDF محلي ضمن ملفات الموقع. لتحديثه استبدلي assets/device-guide.pdf في GitHub بملف PDF الجديد.
- عند بدء استخدام أقسام الإدارة، أضيفي البيانات من لوحة التحكم؛ العناصر غير المضافة لن تظهر في القسم العام.

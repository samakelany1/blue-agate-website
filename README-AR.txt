نظام QR للحضور - Blue Agate Fitness
====================================

هذه حزمة موحدة للرفع على جذر مستودع GitHub، وتحتوي على الملفات الكاملة المعدلة/المضافة:
- index.html (النسخة الأصلية للموقع مع بطاقة QR وإضافة مكتبة QR)
- profile.js (النسخة الأصلية مع توليد QR)
- profile.css (النسخة الأصلية مع تنسيق QR)
- reception.html / reception.css / reception.js (صفحة الاستقبال)

طريقة الرفع مرة واحدة:
1) فكّي ضغط الملف على جهازك.
2) في GitHub افتحي المستودع blue-agate-website > Add file > Upload files.
3) حددي الملفات الستة الموجودة داخل هذا المجلد، وليس ملف ZIP نفسه.
4) ارفعيها إلى جذر المستودع، ثم Commit changes مرة واحدة.

تنبيهات مهمة:
- لا ترفعي firestore-rules-qr.txt ولا تستبدلي قواعد Firebase الحالية بهذه الحزمة؛ يجب دمج قواعد الصلاحيات يدويًا بعد مراجعتها.
- هذه نسخة اختبار. رمز QR يحتوي Firebase UID ثابتًا ويمكن نسخه؛ لا تعتمدي عليه وحده لإثبات هوية العضوة.
- منطق الغياب الحالي يعالج الأيام السابقة عند مسح العضوة التالي، وليس بجدولة تلقائية منتصف الليل.
- لا تستخدمي أرصدة حقيقية قبل اختبار الصلاحيات، تسجيل الحضور مرة واحدة يوميًا، وإدارة الإغلاقات والإيقافات.

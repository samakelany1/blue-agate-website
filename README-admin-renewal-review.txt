تحديث لوحة إدارة طلبات التجديد

ارفعي واستبدلي الملفات التالية في جذر مستودع GitHub:
1) admin.html
2) requests.css
3) renewal-requests-admin.js

لا تستبدلي admin.js أو requests-admin.js أو ملفات الحضور والغياب.

طريقة العمل:
- يظهر الطلب في لوحة الإدارة ضمن طلبات تجديد الاشتراك.
- زر «فتح ملف العضوة» يفتح سجل العضوة في لوحة الإدارة.
- تنفذين التجديد من أزرار التجديد المعتادة الموجودة في ملف العضوة.
- بعد نجاح التجديد وظهور تاريخ نهاية جديد، ارجعي إلى الطلب واضغطي «تم التجديد فعليًا».
- النظام يتحقق أن تاريخ نهاية الاشتراك تغير بعد وقت الطلب قبل السماح بتسجيل أنه تم التجديد.
- إذا لم يتم التجديد، اضغطي «لم يتم التجديد» ويمكن كتابة ملاحظة اختيارية.
- تبويب «كل الطلبات» يعرض الطلبات المفتوحة والمنتهية مع النتيجة وتاريخ تحديث الحالة.

قواعد Firestore التي أضفناها سابقًا تسمح للإدارة بتحديث طلب التجديد، ولا تحتاجين تعديلًا جديدًا للقواعد لهذا التحديث.
منطق التجديد الحالي في admin.js لم يتم تغييره.
